# House-trade-strategy
## 「談判大叔」陳侯勳｜買房投資與談判理論全集

收錄與整理「談判大叔」陳侯勳關於不動產投資、房價形成機制、自住與換屋思維，以及實戰「被動談判」理論之完整知識庫與互動網頁。

---

### 內容亮點

1. **底層邏輯與市場觀**
   - 房價結構解析（土地價值、營造成本、資金寬鬆與通膨傳導）
   - 自住客、置產客與換屋族的決策關鍵
   - 避開買房常見迷思與陷阱

2. **被動談判理論**
   - 逆向思維談判架構
   - 屋主心理與仲介誘因機制
   - 籌碼創造與價格錨定技巧

3. **實戰工具與案例**
   - 現場看屋檢核要點
   - 出價策略與議價攻防
